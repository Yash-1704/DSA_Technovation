A personal collection of my Data Structures and Algorithms solutions, documenting my journey of learning, practicing, and improving my problem-solving skills.

I use this repository to track my daily DSA practice, explore different approaches to problems, and strengthen my understanding of algorithms through consistent practice in Java.

This journey is also part of **[DSAvation](https://dsavation.vercel.app/)**, a daily DSA challenge initiative by **Technovation — The Networking Club**, ABES Engineering College. As the Technical Lead of Technovation, I've guided the development of DSAvation while actively participating in its daily challenges.

## Repository Structure

I organize my solutions by their LeetCode problem numbers, keeping each problem in a separate directory.

```text
DSA_Technovation/
├── 1/
│   └── solution.java
├── 217/
│   └── solution.java
├── 242/
│   └── solution.java
├── ...
├── assets/
│   └── dsavation-badge.png
└── README.md
```

Each solution follows the format:

```text
<problem-number>/solution.java
```

This keeps the repository organized and compatible with DSAvation's GitHub submission verification.

## Daily Progress

I use a consistent commit naming convention to maintain a chronological record of my daily practice.

```text
Day-XX #ProblemNumber Problem Name
```

For example:

```text
Day-01 #217 Contains Duplicate
Day-02 #242 Valid Anagram
Day-03 #1 Two Sum
```

The commit history reflects my progress as I work through new problems and continue building my DSA fundamentals.
